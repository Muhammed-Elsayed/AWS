# AWS Deployment Playground

A small project created while exploring how to deploy a full-stack application on **AWS**.

## Topics Covered

* Deploying applications on Amazon EC2
* Connecting an application to Amazon RDS
* Basic AWS networking and configuration
* Containerizing an application with Docker

## Technologies

* AWS EC2
* Amazon RDS
* Docker
* Node.js

This repository represents hands-on practice with deploying and connecting application infrastructure on AWS.
